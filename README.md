# スキーゲーム（Ski Game）

## ゲーム概要
Pythonで作成したスキーゲームです。
木や崖などの障害物を避けながら、ハイスコアを目指すゲームです。

## 操作方法
- ←：左に移動
- →：右に移動
- Space：ゲーム開始・一時停止・再開
- R：リスタート
- Q：ゲーム終了

## 追加・改良した機能
- 距離に応じてスコアが増える機能
- ライフ機能（ライフは3つ）
- コイン（$）を取ると50点追加される機能
- ベストスコアを記録する機能

## 動作環境
- Python
- Windows
- Visual Studio Code

## 起動方法
ターミナルで `python ski_game.py` を実行します。
